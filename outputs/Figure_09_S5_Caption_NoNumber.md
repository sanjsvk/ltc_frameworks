# S5 Calibration Sensitivity Figure Caption (WITHOUT Figure Number)

**S5 Calibration Sensitivity — Frozen versus Optimized LTC Recovery.** Grouped bar chart comparing LTC recovery accuracy for all 10 models under frozen S1 parameters (hatched bars, all 0%) versus S5-optimized parameters (solid bars). With frozen S1 calibration, all 10 models fail: adstock-based models (F1/F2) and deterministic state-space models (Kalman DLM, BSTS) over-predict LTC by 3x–58x per channel (aggregate MAPE 108%–1854%), while MCMC over-attributes the weak signal via S1-tuned priors. S5-specific optimization—broader parameter searches for F1/F2, re-tuned variance grids for Kalman/BSTS, MAP search for MCMC—reveals the architectural boundary: 9 non-MCMC models remain at 0% recovery because their LTC decomposition is adstock-carryover whose scale is determined by media volume, not signal amplitude. Only MCMC achieves 88.5% recovery by using the explicit latent brand stock parameterisation (stock[t] = δ·stock[t−1] + build_rate·√spend[t]), which allows unconstrained discovery of near-zero δ and build_rate values matching S5's weak signal. The +88.5pp calibration gap represents the maximum achievable improvement, and applies exclusively to the model whose structure matches the data-generating process. *Data source: Section 4.5 S5 supplementary optimization runs.*
