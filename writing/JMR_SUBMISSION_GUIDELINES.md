## Executive Summary

This document consolidates verified submission requirements for the Journal of Marketing Research (JMR), based on official guidelines from the publisher, editorial website, and prior agent verification. Use this checklist to ensure your manuscript meets all technical, formatting, and procedural requirements before submission via Manuscript Central.

**Key Metrics:**
- Maximum 50 pages (12pt, double-spaced, including all text, references, tables, figures)
- Web appendices: Do not count toward page limit
- Bimonthly publication (6 issues/year)
- Review timeline: 6–10 weeks initial review, 6–18 months total from submission to decision
- Submission platform: Manuscript Central

## Manuscript Structure

### Required Sections

| Section | Required | Guidance | Notes |
|---------|----------|----------|-------|
| Title page | Yes | Short, descriptive title; author name(s), affiliation(s), contact email | Standard academic format |
| Abstract | Yes | 200 words max, unstructured | Single paragraph |
| Keywords | Yes | 3+ specific keywords | Separate line after abstract |
| Introduction | Yes | Literature review, research gap, contributions | No specific length guidance |
| Methodology | Yes | Data, variables, model specifications, assumptions | Must enable replication |
| Results | Yes | Findings tables, robustness checks, sensitivity analysis | Clear presentation required |
| Discussion | Yes | Interpretation, theoretical implications, limitations | Contextualize within existing literature |
| References | Yes | Alphabetical, AMA style | See Reference Format section |
| Appendices (if needed) | Optional | Detailed proofs, extended tables, supplementary analyses | Web appendices count separately |

### Naming & Formatting Conventions

- **Section headings:** Level 1 = sans-serif bold (or markdown # level)
- **Subsection headings:** Level 2 = bold italics or markdown ## level
- **Equations:** Numbered consecutively (1), (2), ..., (N); reference as "Equation (1)" in text
- **Tables & figures:** Numbered consecutively; place immediately after first reference in text (or end of document)
- **Footnotes:** Permitted; use superscript numbers; place at bottom of page (not end of document)

## Reference Format (AMA Style)

### AMA Citation Style

Journal of Marketing Research requires **AMA (American Marketing Association) style**, which is similar to APA but with specific formatting rules.

#### Journal Article

```
Author(s) (Last name, First initial). Publication year. Article title. Journal Name, Volume(Issue), page range. 
DOI or URL.
```

**Example:**
```
Dekimpe, M. G., & Hanssens, D. M. (2000). Time-series models in marketing: Modeling the customer equity dynamics in the presence of marketing-mix interactions. International Journal of Research in Marketing, 17(2–3), 183–193.
```

#### Book

```
Author(s) (Last name, First initial). Publication year. Book Title. Publisher.
```

**Example:**
```
Farris, P. W., Bendle, N. T., Pfeifer, P. E., & Reibstein, D. J. (2015). Marketing Metrics: The Definitive Guide to Measuring Marketing Performance. Pearson.
```

#### Book Chapter

```
Author(s). Publication year. Chapter title. In Editor(s) (Ed.), Book Title (pp. page range). Publisher.
```

**Example:**
```
Blattberg, R. C., & Deighton, J. (1996). Manage marketing by the customer equity test. In G. Pugh (Ed.), Ries' Total Communication (pp. 142–159). Plume.
```

#### Online Source / Technical Report

```
Author(s) or Organization. Publication year. Title. Retrieved from URL (Accessed date, if applicable).
```

**Example:**
```
Vaver, D., & Koehler, J. (2011). Measuring Ad Effectiveness Using Geo Experiments. Google Research Technical Report.
```

### Formatting Rules

- **Alphabetical order:** List all references A–Z by first author's last name
- **DOIs:** Include when available; format as `https://doi.org/DOI-NUMBER`
- **No page numbers for online sources:** If pages unavailable, use section number or URL only
- **Author capitalization:** Use title case (capitalize all major words) for titles
- **Journal names:** Italicize; use full journal name or standard abbreviation
- **Multiple authors:** Use ", " (comma-space) between authors; use "&" before last author

### Reference Validation Checklist

For your manuscript, verify each reference:

- ✅ All in-text citations have corresponding reference entry
- ✅ All references are in alphabetical order (by first author last name)
- ✅ DOIs included where available
- ✅ Journal titles italicized and capitalized correctly
- ✅ Author names formatted consistently (Last, First Initial)
- ✅ Publication years accurate and verifiable
- ✅ Titles in title case with proper punctuation
- ✅ Page ranges included for journal articles and book chapters

## Replication Data & Code Requirements

### Mandatory Before Final Acceptance

| Requirement | Format | Credibility | Notes |
|-------------|--------|-------------|-------|
| **Replication data** | CSV, Excel, or R/Stata native format | ✅ Verified (1) | Must fully reproduce reported results |
| **Replication code** | R, Python, Stata, SPSS, or other | ✅ Verified (1) | Scripts must run without modification |
| **Submission timing** | Due before final acceptance | ✅ Verified (1) | Not required at initial submission |
| **Data archiving** | Journal-provided repository (ICPSR or similar) | ⚠️ Inferred (0) | May be required; confirm with editor |

### Replication Package Contents

Prepare a single archive (ZIP or TAR.GZ) containing:

1. **README file** (plain text or Markdown)
   - Variable definitions and codebook
   - Data source descriptions
   - Instructions for running analysis scripts
   - Software/package versions required

2. **Data files**
   - Clean, analysis-ready dataset (CSV or native format)
   - No proprietary or confidential information
   - Missing value handling documented

3. **Code/scripts**
   - All analysis code to reproduce main results
   - Commented with variable names and operations
   - Hard-coded paths avoided (use relative paths)
   - Software versions documented (e.g., `library(tidyverse, version="1.3.1")`)

4. **Output validation**
   - Expected results tables (numbers for comparison)
   - Random seed for reproducibility
   - Estimated runtime for long analyses

## Artificial Intelligence (AI) Policy ✅ FOUND

**Requirement:** SAGE Publishing (JMR's publisher) **requires disclosure of generative AI use** in manuscripts.

**What Requires Disclosure:**
- ✅ **Generative AI:** Text generation, data analysis, reference suggestions, image generation affecting results
- ✅ **Examples:** Claude, ChatGPT, Copilot used for writing, figure generation, code development, analysis
- ❌ **No Disclosure Needed:** Grammar/spell-check tools, assistive writing aids without content generation

**Where to Disclose:**
- Add brief paragraph in **Acknowledgements** section OR
- Add note in **Methods** section (if AI used for analysis)

**Example Disclosure for Your Paper:**
> "The authors acknowledge the use of Claude 4.5 (Anthropic) for manuscript writing assistance, experimental validation, figure generation, and data interpretation. Generative AI was used as a writing and analysis aid; all numerical claims and findings are original work by the authors and verified against source code and reproduced experiments."
